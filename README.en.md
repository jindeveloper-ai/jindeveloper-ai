## [Risu Extensions](https://github.com/jindeveloper-ai/risu-extensions-portfolio)

Three extensions for **Risu, an AI chat frontend**: turn conversations into audiobooks, explore inner thoughts, and switch reading themes.

<picture>
  <source media="(max-width: 600px)" srcset="https://raw.githubusercontent.com/jindeveloper-ai/risu-extensions-portfolio/main/docs/screenshots/audio-library-mobile.png">
  <img src="https://raw.githubusercontent.com/jindeveloper-ai/risu-extensions-portfolio/main/docs/screenshots/audio-library-desktop.png" alt="Audio Book Maid library and resume playback controls, running the real UI with synthetic demo data." width="760">
</picture>

*Real UI, synthetic demo data. No private conversations.*

- **[Audio Book Maid](https://github.com/jindeveloper-ai/risu-extensions-portfolio/tree/main/projects/audio-book-maid)**: Assign voices, review scripts, generate audio, and pick up where you left off.
- **[Doki Doki](https://github.com/jindeveloper-ai/risu-extensions-portfolio/tree/main/projects/doki)**: Generate, save, and reopen inner thoughts for a selected response.
- **[PocketRisu Theme Switcher](https://github.com/jindeveloper-ai/risu-extensions-portfolio/tree/main/projects/pocket-theme-switcher)**: Apply presets, use dark mode, and restore your original theme.
