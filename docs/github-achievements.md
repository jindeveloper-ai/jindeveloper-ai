# GitHub Achievements 획득 메모

GitHub 활동 조건을 충족하면 프로필에 자동으로 추가되는 배지입니다. 별도 신청 버튼은 없습니다. 지급과 표시에는 지연이 있을 수 있습니다.

## 획득 조건

| 업적 | 기본 조건 |
| --- | --- |
| Quickdraw | 이슈 또는 PR을 연 뒤 5분 안에 닫기 |
| YOLO | 본인이 연 PR을 리뷰 없이 병합하기 |
| Pull Shark | 본인이 연 PR 2개가 병합되기. 이후 16 / 128 / 1,024개에서 상위 등급 |
| Pair Extraordinaire | 실제 공동 작업자를 공동 작성자로 기록한 커밋이 포함된 PR 병합 |
| Galaxy Brain | 저장소 Discussions에서 답변 2개가 채택되기 |
| Starstruck | 본인이 만든 저장소가 별 16개 받기 |
| Public Sponsor | GitHub Sponsors로 개발자 또는 조직 후원하기 |

조건과 등급 수치는 아래 커뮤니티 자료의 관찰값이며 GitHub가 변경할 수 있습니다. 과거 한정 업적인 Arctic Code Vault Contributor와 Mars 2020 Contributor는 지금 새 활동으로 받을 수 없습니다.

## 확인 및 표시

- [내 업적](https://github.com/jindeveloper-ai?tab=achievements)에서 배지를 누르면 관련 활동과 등급을 확인할 수 있습니다.
- [공개 범위 설정 안내](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements)를 참고하면 비공개 기여의 업적 표시 여부를 관리할 수 있습니다.
- GitHub Community Discussions에서는 업적을 받을 수 없습니다. 다른 저장소의 Discussions와 구분해야 합니다.
- 공동 작성자, 답변 채택, 별은 실제 협업과 다른 사용자의 활동을 통해 얻습니다.
