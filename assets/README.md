# Profile assets

The static `profile-header.svg` was generated with [capsule-render](https://github.com/kyechan99/capsule-render) on 2026-11-03.
It uses a fixed blue background and sans-serif font fallbacks. The service's default fade-in, unused description style, and invalid empty stroke value were removed to make the result static. The SVG is stored in this repository so the profile does not need to request the renderer on every visit.

Source request:

```text
https://capsule-render.vercel.app/api?type=soft&color=244A68&height=144&text=SUJIN%20LEE&fontColor=F6F8FA&fontSize=68&fontAlign=28&fontAlignY=62&fontFamily=Arial&section=header
```

The [GitHub Profile README Editor](https://github-profile-readme-editor.netlify.app/) was used to configure the header, introduction, and flat-square technology badges. Its output was adapted to native GitHub Markdown, the four project languages, bilingual content, and the user's LinkedIn link.
